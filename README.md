# scrap-io

A minimal, modern, single-page code scratchpad for technical interview preparation.

- Pure static app (`index.html`, `style.css`, `app.js`) — no backend, no build step.
- Monaco Editor via CDN with dark, distraction-free defaults.
- Language switching, font size controls, tab-size toggle, clear/copy actions, optional timer.
- Local autosave for language and buffer using `localStorage`.
